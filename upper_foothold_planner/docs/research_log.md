# 研究日志

只记录当前阶段的设计决定与结论，不记录单次微调/超参扫描。

## V4：宏观状态监督（当前）

### 问题诊断

此前（V1–V3）世界模型用"完整观测一致性"监督隐空间——让隐状态预测并重建下一帧深度图
（或对下一隐状态的完整编码做一致回归）。结果是：隐状态被拖向视觉重建，模型学到的是
深度图的像素/编码结构，而**没有学到任何关于任务（是否前进、是否碰撞、是否跌倒、是否
到目标）的有效信息**。上层策略因此无法规划出有意义的行为。

### 决定

1. **去掉完整观测重建/一致性**。
2. **用 21 维宏观运动状态监督 dynamics**：基座高度、线速度、角速度、姿态、脚在基座系
   位置、步态相位、相对目标。`task_state` head 从 `next(z,a)` 预测这 21 维，smooth L1，
   仅对 alive 样本取平均。
3. **时间尺度改为步态切换步数**：`option_duration` 按 tick 数（÷25）监督，时间奖励按
   `option_ticks/25` 缩放，折扣按选项时长衰减。
4. **第一阶段不追求泛化**：只在 `random_composite` 单场景上训练到"绝大多数环境能完成
   任务"。
5. 保留事件 head（collision/fall/goal/off_support）与连续 margin head（碰撞力/稳定裕度/
   支撑占比/触地误差），让任务信号显式可分，而不是被压进标量 reward loss。

### 第一阶段配置

```text
--research_kind random_composite --course_length_m 3.5
--num_envs 2048 --max_updates 100000 --model_variant option
--collection_policy mixed --mixed_planner_fraction 0.5
--planning_disable_goal --planning_base_safety_scale 0.5 --terminal_value_coef 0
```

### 成功标准

绝大多数环境能走到目标（距离 < 0.30 m），且碰撞/跌倒可控。

## V5：奖励修正 + 反向课程重置（当前）

### 问题诊断（训练数据实证）

2048 环境训练中 `reward_goal = 0.0`（从未到达目标）、`distance_mean_m ≈ 2.5`（平均只走到
离起点 ~0.9 m 就摔），净奖励恒为负（`reward_mean ≈ −1.3`）。两个根因：

1. **惩罚主导**：off_support −10（单点误判）+ fall −10 + collision 阈值 1 N（全身非足刚体，
   正常走路小腿/膝盖蹭地误判），惩罚合计是 progress 的 2 倍多，策略被压成“保守不动”。
2. **目标奖励永不可达**：机器人每次重置都从起点出发，从未见过后半段赛道，+10 的 goal
   永远拿不到。

### 决定

1. **off_support 改用 3×3 九点支撑占比**：二元目标 `support_fraction < 0.5`，奖励改分级
   `−3·(1−support_fraction)`（量级 −10→−3），消除边缘误判。
2. **collision 阈值 1 N → 5 N**（`collision_force_threshold_n`），消除正常行走的蹭地误判。
3. **fall 量级 −10 → −5**。
4. **反向课程重置**：以概率 0.5 在赛道中段随机支撑位置重生（距目标 ≥0.6 m、距起点
   ≥0.5 m、3×3 全支撑），让模型经历中段/接近目标状态，使 goal 可被采样。评估仍从起点。

progress 是差分（`previous_distance−distance`），重置时重新锚定到当前位置，因此中间位置
重置不会白送 progress，也不会诱导“主动摔倒重置”。

## 已放弃的方向（避免重走）

- **V1/V2 深度重建监督**：隐状态学视觉而非任务。
- **V3 策略先验**：给 CEM 加策略先验/策略 rollout 能提高进度，但安全（跌倒/碰撞）退化；
  属于微观调整，不是根因。
- **Q-max 项（policy_q_coef）**：发散或更激进，弃用。
- **安全过滤（policy_safe_only）**：无效果，弃用。
- **安全与激进的平衡、安全先验**：根本问题不是这个，而是策略没学到任务信息。

## 结论备忘

- 宏观状态（不是完整观测）才是落足选项隐动力学的正确监督信号。
- 一致性损失会拖累任务学习；先证明单场景跑通，再谈课程/域随机化。
