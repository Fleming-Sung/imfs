# 训练规模扩大计划（2026-09-07 第二轮）

第一轮结果：学习世界模型 H1 在硬地形上显著优于贪心基线（完成 9–11/64 vs 0/64，前进
距离 ~2 倍，跌倒 ~1/2），但**绝对完成率仍低**。根因：① 下层只验收 ±4 cm，硬地形
（台阶 5 cm、梅花桩 ±5 cm）已顶到能力边缘；② 上层模型容量与数据量仍偏小。

本轮目标：**同时放大下层与上层的训练规模与模型容量**，让算法学到更多有效信息。

## 执行顺序（依赖关系）

```
重训下层（±6 cm，更多迭代）→ 新下层哈希
    → 用新下层大规模采集（8 分片，~16M 交互）
    → 训练更大容量的上层世界模型（从零，更多更新）
    → 运动模型
    → 同种子 H1 vs 贪心 评估 + 视频
```

## 改动清单

1. **下层**（`lower_controller_3d/`，不改代码、只改训练参数）：
   - `--height_range 0.06`（z 课程从 ±4 cm 扩到 ±6 cm，匹配台阶/梅花桩高差）；
   - `--height_ramp 300`（更慢的课程）；
   - `--num_envs 2048`、`--iterations 1000`（200 → 1000，约 5× 训练量）。
2. **上层模型容量**（`composite_terrain/train.py` 新增 CLI）：
   - `hidden_dim` 256 → 512，`geometry_dim/dynamics_dim` 64 → 128（潜状态 128 → 256）；
   - 从零训练（容量变化无法暖启动旧 checkpoint）。
3. **上层数据**：8 × 256 环境 × 8000 tick ≈ **16.4M 交互 / ~670k 转移**（第一轮的 2 倍）。
4. **上层训练**：batch 1024，**30,000 更新**。

## 验收 / 对比

- 下层：±6 cm 高度目标，64 env × 20 s，无跌倒环境占比与 XY/Z 中位误差；
- 上层：难度 0.5，seed 9801/9901，H1 vs 贪心；与第一轮（9–11/64）直接对比；
- 全程 TensorBoard（下层 `runs/<lower_run>/tb`，上层 `runs/composite3d_hard_big/tb`）。

## 资源与时间估计

- 下层 1000 iter × 2048 env（~24 步/iter ≈ 49M 交互）≈ 25–40 min；
- 采集 8 分片 ≈ 40 min；上层 30k 更新 ≈ 25 min；运动 + 评估 ≈ 10 min。
- 总计约 **1.5–2 小时**，全部自动化、可断点续跑。
