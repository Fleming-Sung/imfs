# 三维复合路线世界模型：当前方法与证据边界

## 2026-09-07补充：V8诊断与V9数据覆盖

V8的细化动作重训、独立三步风险、终点物理进展改分、完整180候选覆盖均未稳定提升两个难图开发seed的完成率，保留为消融分支，不叠加成未经证实的默认方法。

三步风险标签为真实episode内未来最多三步的任意跌倒/碰撞，短真实终止不丢弃；未观测满窗口且非真实终止的截尾不标成安全。风险网络输入冻结编码＋75维控制状态＋实际4维动作；只学习行为分布下条件风险，不宣称得到各动作的因果风险。留出Brier下降而闭环无提升，说明校准本身不保证更好的动作选择。

终点代价实验以学得身体位移计算 `||g_body|| - ||g_body - Δxy_hat||`，代替终点附近理想脚点进展；`Δxy_hat`仍来自世界模型，不查询未来仿真。不改变任务200ms稳定到达要求。该改分也未跨seed改善。

V9采集行为为 `π_collect = 0.88 π_V7_H1 + 0.12 Uniform(A_current_support)`。支撑候选只使用当前观测地形；每个选中动作都实际执行，未执行候选只能有静态几何标签，不能获得伪造的动力学结果。评估探索概率为零。保留原4维动作、75维观测及冻结下层；用1024新布局补足动作/参数覆盖，检验数据覆盖是否为瓶颈，而不是增加模型展开长度。

训练资源：仅对决策环境构建观测、同决策复用当前地图；合并池以只读NPY memmap访问，序列审计按4096行分块。GPU中的静态地图缓存保持uint8，批次选出后才转浮点。没有改变观测数值/成功标准，也未宣称未经计时对照的加速倍数。

## 2026-09-07补充：V5–V7物理锚定展开

V4严格H1/H3对照为23次/4次完成，多步自由潜展开负增益。因此V5不继续盲目加深该潜模型，而采用结构分解：

`(Δx,Δy,Δyaw,Δz_stance, p̂_next) = F_θ(h(H,p), p, a)`

`T̂_next = T̂ ⊕ ΔT`，`Ĥ_next = crop(M_current, T̂_next)`。

M是当前时刻观测的128×128静态局部缓存；未来只改变由模型预测的观察位姿和支撑高度。F由3个网络预测闭环运动/状态，监督为真实下层执行的转移；指令历史、左右脚交替和目标坐标变换显式更新。原V4编码器/结果头冻结复用，减少训练资源。规划展开只使用张量，不能访问环境或未来物理状态。

这是新的世界模型假设，不是“完美跟踪动作目标”的运动学替代。V5缓解了自由潜展开的退化，但V6/V7扩量后H3仍未稳定优于H1；完整统计见[进度](progress_2026-09-07.md)。更大当前缓存也是信息变化，后续必须在相同缓存下比较学习运动、简单运动学与H1/H3，才能建立论文贡献。

V7增加当前模型执行产生的真实replay，与几何引导数据混合。P4c进一步对上述物理展开做三步反向传播：每步只从初始已观测缓存重投影，用真实连续执行的累计位姿T、下层状态p和脚部状态p_foot监督。

`L = mean_{k=1..3} [Huber(T_hat_k / scale, T_k / scale) + 0.25 Huber(p_hat_k,p_k) + 0.25 Huber(p_hat_foot,k / 0.05,p_foot,k / 0.05)]`。

位姿包含XY、yaw及支撑高度；scale=(0.25m,0.10m,0.15rad,0.04m)。非终止连续序列才能进入该损失，终止/跌倒仍由结果模型监督。编码器和下层冻结，物理模型可微展开；不把真实下一图像当作展开输入。此训练仅降低当前留出序列的累计预测误差，闭环收益另测。

评分消融允许在几何代理与已学实际执行奖励间切换：`s=(1-w)s_geometry + w*r_hat - uncertainty`，终端Q和延续项不变。V6 w=1难图20/64、默认18/64，尚不足以说明它优于旧V5或取得显著突破。当前默认w=0，所有试验记录具体权重。

## 输入、动作与真正学习的动力学

下层是独立短训后冻结的XYZ落脚控制器。一次上层动作持续至下次换脚：

`a_t = (x, |y|, dz, yaw)`，4×3×5×3＝180候选；x范围12–30cm，横向12–24cm，dz为−8/−4/0/4/8cm，yaw为−6/0/6度。XY在支撑脚yaw系解码，Z相对实际支撑脚，加入与旧V6一致的转弯横向项。±8cm包含探索/失败样本，下层主要验收范围仍为±4cm，不能声称所有候选均可靠可达。

`o_t = (H_t, p_t)`：当前64×64真实局部高度图（相对支撑脚高度，范围3.15m）＋75维状态。状态包含机器人姿态/关节/速度、脚相对位置、步态相位、目标相对位置、上一上层动作、支撑脚标识，以及**下层当前16维目标观测和两帧关节动作历史**。后两项避免相同身体姿态但保留落脚目标/控制历史不同造成闭环转移混叠。当前是理想地形观测研究，不引入虚拟视觉误差。

`z_t = [g_t, d_t] = h_θ(o_t)`，几何潜变量和动态潜变量各64维，使用SimNorm。

`ẑ_{t+1} = f_θ(z_t, a_t)`，与冻结下层真实执行后的 `h_EMA(o_{t+1})` 对齐。训练连续H1→H3序列；非终止样本的next observation须与下一条decision observation逐元素相等。终止样本保留奖励/风险监督，但屏蔽自动reset状态的一致性损失。没有把理想脚点平移当作真实机器人动力学。

## 学习信号与推理边界

真实奖励为 `r = 10·ΔΦ_body − 5·fall − 2·collision − 2·(1−support) + 10·arrival`。V3的Φ使用到终点的直线距离势；V4改为静态可通行落脚图的距离势，下降量仍在**实际机器人移动后**计算。落脚误差和跌倒/碰撞/延续概率也来自真实执行。

候选几何头监督每个当前候选的支撑率、落脚点距离势下降量和提案方向，动态风险只监督执行过的动作。注意：当前规划中的`progress`头主要对应**候选几何进展**，不能当成独立的真实机身位移预测精度；真实机身进展通过奖励头及潜状态转移约束进入模型。后续需验证奖励头参与规划是否有额外价值。

V4训练期落脚图标签允许读取完整静态地图，但不读取未来物理状态，不使用地形生成器中心线。图边允许小间隙、限制端点高度差并考虑边界余量；它只引导采集/训练，不证明动作在动力学上成功。正式模型推理拒绝开启该全图标签接口。

离线值学习采用下一条replay真实动作进行SARSA式bootstrap，得到的是行为数据支持的值估计，不宣称已求得最优Q。提案先验主要缩小离散搜索范围；EMA编码、潜状态动力学、结果预测及值估计共同训练，不训练一个端到端PPO老师再蒸馏。

推理时在学习的潜状态中做H3 beam search，执行首动作后重新观测。当前可选支撑约束仅检查当前脚点邻域的真实可观测地形；未来步骤仍由世界模型展开，不做未来仿真查询。默认评分包含几何进展、跌倒/碰撞风险、预测支撑和小权重终端值。必须用相同检查点比较H1/H3、禁用动力学/风险等消融，才能证明世界模型本身有用，而不仅是静态落脚选择有效。

## 当前证据与下一门槛

V3在64张从起点出发的复合路线、60s预算下，18张到达终点，累计134跌倒，64个尾部截尾episode；不是“几乎完成全部任务”。该结果比首轮0到达有改善，但数据量、状态和TD实现同时变化，不能拆解成单因素贡献。

此前arrival只要求进入终点30cm范围；后续正式评估增加直立、正常机身高度、无非脚碰撞且持续200ms，并保存逐episode记录。不同成功判据必须分别报告，不能直接混算成功率。所有结论以 [实验日志与视频](composite_3d_experiments.md) 为准。
