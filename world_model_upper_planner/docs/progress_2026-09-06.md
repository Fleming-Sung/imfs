# World-model upper planner progress report

Date: 2026-09-06

## Executive status

The main method is functional and has already demonstrated a genuine
world-model planning benefit. The current formally selected model is V6
risk-H3, not the unfinished V8 branch. V6 uses a learned latent transition and
finite-horizon risk critic to plan three upper foothold options through the
frozen lower controller. Across 36 held-out closed-loop evaluations it is
strong on bridge, household and irregular terrain, but edge and stepping-stone
courses remain the main failure domains.

The most important new finding is that stepping-stone performance is partly
limited by lower-controller target realization. An isolated lower variant
improved a three-seed capability probe from 18.6% to 30.7%, but the formally
required lower-consistent world-model retraining is incomplete. No active
training process exists at the time of this audit.

## Current architecture and validated result

The upper planner observes simulator-true local terrain and deployable robot
proprioception, encodes them into split geometry/dynamics latents, and learns
the frozen-lower closed-loop option transition

`z_(t+1) = f(z_t, a_t)`.

It predicts per-candidate progress, support, touchdown error and value. A
separate finite-horizon critic predicts fall/collision risk. Beam search chooses
the first option from a three-step imagined sequence, then replans after the
real lower controller executes it. It does not use teacher actions, future
simulator state, task outcome, continuous CEM, or a learned goal-probability
head at inference.

Selected V6 risk-H3 results:

| scenario | success |
|---|---:|
| research nominal / hard | 80.7% / 41.4% |
| turns nominal / hard | 47.1% / 29.8% |
| household nominal / hard | 78.7% / 67.4% |
| bridge nominal / hard | 100.0% / 94.2% |
| edge hard | 37.2% |
| stepping stones hard | 21.8% |
| irregular nominal / hard | 97.3% / 83.4% |

These are three held-out seeds per scenario, 32 environments and 1,000 lower
ticks per run. V6 training used 749,541 upper transitions, 24,576 procedural
layouts and 18.432 million lower-environment interactions. The complete table
and ablations are in [scale_training_v6.md](scale_training_v6.md).

## Trajectory-driven diagnosis and isolated lower branch

Failure videos and retained trajectories showed 0.10--0.35 m target-to-foot
errors on some stepping-stone approaches, versus roughly 0.01--0.04 m on
ordinary options. Static geometry shields, a scalar touchdown penalty, landing
chance scoring and learned command inversion were tested and rejected because
they reduced closed-loop completion.

The optional lower branch is isolated under
`adapters/lower_tracking_adaptation/`; neither the original lower source nor
the teacher-student/PPO baseline was modified. The selected diagnostic variant
was fine-tuned for 40 PPO iterations and has SHA-256
`bbd87522ab27aa25238f6d14af96fea5cd481ca76a89187e4fc08cb94f42dd7b`.

| stepping-stone seed | original lower | isolated V2 lower |
|---:|---:|---:|
| 5101 | 21.2% | 34.5% |
| 5102 | 19.7% | 35.2% |
| 5103 | 14.9% | 22.4% |
| mean | 18.6% | 30.7% |

This is a capability result, not a final planner comparison: the upper model in
this probe was still trained with the original lower dynamics. The all-action
audit also found a small left-turn fall-rate regression, so V2 has not replaced
the original lower controller globally.

## V8 formal run: exact current state

The V8 pipeline now binds collection and evaluation to an explicit lower
checkpoint and records its hash in both the experiment manifest and shard
summaries. Reusing the namespace with another lower hash is rejected. A full
12-scenario smoke pipeline completed collection, replay merge, H1/H3 training
and short execution checks; 12 unit tests pass.

The formal scale run was interrupted on 2026-09-02 after two of twelve shards.
It did not remain active in the background:

## Research conclusion and next gate

The defensible paper-level result today is: candidate-grounded multi-step world
model planning plus learned finite-horizon risk improves difficult closed-loop
foothold planning over the same model's one-step and unregularized alternatives,
while discontinuous supports expose an action-realization bottleneck.

The next necessary step is to resume V8, collect the remaining ten lower-
consistent shards, retrain H1/H3 and risk models on only that replay, and repeat
the identical 36 held-out evaluations plus hard-scenario videos. V2 should be
accepted only if edge/stones improve without material regression on bridge,
household and irregular terrain. Until that gate passes, V6 risk-H3 remains the
selected method.
