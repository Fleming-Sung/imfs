# 第三轮结果与回归诊断（细 dz + 回退 + Q 价值）

日期：2026-09-07。第三轮改动：候选 dz 2 cm（324 候选）、0 候选回退、学习 Q 价值进评分、
H3 多步规划。结果**完成率从 8/64 回退到 3/64**。本文用同 checkpoint 的规划器级消融定位原因。

## 消融结论（逐项归因）

1. **回退方式是回退主因**：同一 checkpoint，仅把回退从 minimal 换回 max-support，
   完成率 **2 → 6**。minimal 原地小步在 ~19% 的"0 候选"状态里让机器人原地踏步不前，
   是最大回退来源。→ **已把默认回退改回 max-support**。
2. **细 dz 轻微负贡献**：max-support 下第三轮 6/64 vs 第二轮 8/64。原因：细 dz 让
   多样采集采样到 ±8 cm 动作，而下层只验收 ±6 cm，这些动作落足 z 误差大（中位
   0.33→1.8 cm）、制造噪声数据。→ **已把 dz 收窄到 ±6 cm（7 档、2 cm 步进，252 候选）**。
3. **Q 价值轻微正贡献**：minimal 回退下 Q=1.0 比 Q=0 多 1 张完成（3 vs 2），H3 同理
   （3 vs 1）。→ Q 价值保留。
4. **多步 H3 中性**：H3（3/64）≈ H1（3/64），未带来额外收益，但也没有伤害。

## 细 dz 在几何层面的真实效果

对比新旧数据（stones 梅花桩）：

| 指标 | 180 候选（粗 dz） | 324 候选（细 dz） |
|---|---:|---:|
| 平均几何有效候选 | 19.7 | **48.2** |
| 0 候选状态占比 | 19.7% | 19.0%（几乎不变） |

细 dz **显著增加了"有候选"状态的候选数**（19.7→48.2），但**没有减少"0 候选"状态**——
说明 0 候选的根因是**窄桩上的横向/位置不可达**，而非 z 分辨率。dz 细化解决了"候选太少"
这一半，没解决"完全没有候选"这一半。
