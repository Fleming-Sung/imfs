# 硬地形扩量训练结果（dev-2026-09-07 第一轮）

日期：2026-09-07。任务：在加难后的连续复合地图上，验证"候选约束选项世界模型"相对
几何贪心基线的优越性，并检验训练规模（数据量、更新数）是否足够。

## 地形加难（相对上一版）

| 地形要素 | 旧值 | 新值 |
|---|---|---|
| 台阶每级高度 | 1.5–4 cm | **4–6 cm**（5 级累计 20–30 cm） |
| 梅花桩桩顶高差 | ±1–3 cm | **±4–6 cm**（相邻桩最大 ~12 cm） |
| 梅花桩踏面/间隙 | 27 cm 宽、~3 cm 间隙 | **22→19 cm 宽、6–9 cm 间隙** |
| 坡道/不平地 | 4–12 / 0.8–2.5 cm | 6–20 / 1.5–4.5 cm |

冻结下层：`lower3d_v2_z04/model_7200.pt`（XYZ+yaw，±4 cm 验收）。本轮**未改动下层**。

## 训练规模（本轮）

- 数据：4 × 256 环境 × 8000 tick = **8,192,000** 次下层交互，1024 张布局，
  **335,223** 条 option 转移（七类地形各 4.4–5.6 万条，跌倒 5.0%，91.8% 状态有可行候选）。
- 世界模型：**20,000** 更新（V8 暖启动，batch 1024）；selection_score 0.086 → **0.0685**
  （最佳 checkpoint 在 19,750 步）；val_loss 18.6 → 13.6。
- 运动模型：5,000 更新（13 s）。

## 结果：学习世界模型 H1 vs 贪心几何基线

难度 0.5，64 张七类地形连续路线 × 60 s，严格稳定到达判据（30 cm 圈 + 直立 + 200 ms）：

| 指标 | 学习世界模型 H1 | 贪心几何基线 |
|---|---|---|
| seed 9801 完成地图 | **9 / 64** | **0 / 64** |
| seed 9901 完成地图 | **11 / 64** | **0 / 64** |
| 跌倒次数 | 236 / 210 | 526 / 529 |
| 最远前进均值 | 11.18 / 11.81 m | 6.07 / 5.89 m |
| 落足 XY / Z 中位误差 | 3.8 / 0.33 cm | 4.1 / 0.45 cm |

## 结论

1. **新算法在真正困难的地形上体现了明显优越性**：贪心基线 0 完成、~530 次跌倒、平均
   前进 6 m；学习世界模型 H1 完成 9–11 张图、跌倒不足一半、前进距离约 2 倍。
2. 落足精度两者相当，说明差距来自**选点决策**（学到的动力学可行性）而非下层执行。
3. **绝对完成率仍低（14–17%）**：地形已顶到冻结下层 ±4 cm 验收上限边缘。下一轮需
   ① 重训下层扩到 ±6 cm，② 增大模型容量，③ 显著增加数据量，④ 更多训练更新。
