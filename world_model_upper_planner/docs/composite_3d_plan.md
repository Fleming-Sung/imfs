# 三维落脚控制器与连续复合地图：实施计划

建立日期：2026-09-06。状态：执行中。用户指定的后续主线；V8 单场景扩量暂停。

## 目标与边界

在给定、冻结的三维落脚下层控制器上，训练基于 TD-MPC 思想的世界模型上层规划器，在一张包含多种地形和任务的连续地图中完成导航。论文贡献集中于上层闭环动作模型、跨地形规划和泛化。下层只训练到能够稳定行走并大致跟踪 XYZ 目标，避免长期精调。

原有 `foothold/`、师生/PPO `upper_foothold_planner/` 及其检查点完整保留。新下层放在 `world_model_upper_planner/lower_controller_3d/`，复制必要实现并独立维护；新地图与上层适配放在本项目新模块内。原始下层及 V6 结果作为固定参照。

## 原理和实现选择

下层依据本地论文《Mind Your Steps》IV-B、Appendix G（[作者项目页](https://montenegroalessandro.github.io/mind-your-steps/)）：先采样相对支撑脚的目标 `(dx, dy, dz, yaw)`，然后为该目标放置物理支撑面。`p_target,z = p_stance,z + dz`；地形跟随目标生成，禁止从既有地形反查训练目标。用轮换的空闲支撑柱保留当前两脚支撑，采样和碰撞可行性检查先于物理执行。训练 actor 仅使用本体观测、相位与支撑脚坐标系目标，不依赖虚拟视觉。初始平地策略暖启动，高度分布从小幅上下台阶逐步拓宽；验收时固定支撑，不随误差移动落点。论文的自适应落地若使用，须单独标注且不能进入正式评估。

上层使用真实局部高度与障碍观测、目标相对位姿和下层动态状态。潜状态须保留地形几何、身体运动、支撑脚/相位及目的地信息；动作包含 XYZ 落脚和转向。世界模型学习真实下层执行后的 transition，而非理想运动学。奖励由实际导航进展、完成、跌倒、碰撞及失去支撑构成；辅助目标包含落脚误差和三维运动。地形几何监督只用于训练；部署阶段地形高度作为当前观测输入，不读取未来状态。新下层冻结后重新采集 replay 并绑定哈希。

地图不是若干孤立任务的拼盘：每个 episode 沿一条跨越多种区域的连续路线到达目的地。程序化生成坡地、平台、上下台阶、不同高度梅花桩、窄桥、曲线窄路、碎块/不平地、多障碍绕行区、组合缝隙；变化包括顺序、尺寸、坡度、高度、间隙、转角、障碍密度和起终点。先保证连通及下层能力范围内的可行性，再增加难度。保留按组件的测试集，主指标改为复合路线完整完成率及跨区域转换成功率。
