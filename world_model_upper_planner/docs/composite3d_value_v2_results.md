# 第四轮结果：修复后的多步价值 + 细 dz（v2）

日期：2026-09-07。在第三轮回退诊断基础上修复（回退 max-support、dz 收窄 ±6 cm），
重新训练并评估。本轮首次得到**多步规划（H3）显著优于单步（H1）**的闭环证据。

## 配置对比（本轮 v2）

- 候选：dz **±6 cm、2 cm 步进（7 档，252 候选）**；
- 回退：**max-support**（0 候选时踩最稳的近旁点）；
- 评分：几何进展 + 风险 + **学习 Q 价值（value_weight=1.0）**；
- 训练：世界模型 **H1 20k + H3 10k**，运动模型 + 3 步序列校准；
- 评估：同一 `h3_best.pt` checkpoint，仅改规划时域（H1=单步，H3=三步 rollout）。

## 关键结论

1. **回退修复见效**：完成率从第三轮 3/64 恢复到 9–10/64，超过第二轮（8/64）。
2. **多步规划首次显著正收益**：同一 checkpoint，H3 比 H1 多 **+3（9801）/ +7（9901）** 张完成，
   跌倒更少（211/190 vs 271/237），最远前进更长（11.11/12.76 m vs 10.39/10.69 m）。
   这验证了"长期价值 + 多步预测"的假设——正是用户指出的 MDP 核心点。
3. 细 dz（±6 cm、2 cm）与 Q 价值共同贡献了这一提升（第三轮消融已分别确认 Q +1、细 dz 去噪）。
